# Local Network Image Sync (UDP Broadcast)

Проект представляет собой распределенную систему из двух десктопных UI приложений, общающихся по локальной сети без необходимости ручного ввода IP-адресов.

## Архитектура

Проект состоит из двух независимых узлов:

**Пульт управления (`button_app.py`)** это приложение с большой кнопкой "сменить картинку". При нажатии отправляет Broadcast сигнал `TRIGGER_NEXT_IMAGE` по всей локальной подсети на порт `49152`. Целевая платформа**Windows**.

**Экран (`display_app.py`)** это приложение для демонстрации изображений. Запускает фоновый поток, который слушает порт `49152`. При получении команды от пульта переключает картинку на следующую. Целевая платформа **Linux**.

### Основные функции:

* **Auto-discovery (UDP Broadcast)**: Устройства находят друг друга автоматически, если находятся в одной Wi-Fi сети.

* **Генерация заглушек (Fallback)**: Если папка с картинками пуста, приложение "Экран" автоматически генерирует цветные изображения с номерами кадров прямо в оперативной памяти.

* **Кроссплатформенность**: Написано на Python с использованием встроенной библиотеки Tkinter. Поддерживается сборка в исполняемые файлы в `.exe` для Windows, нативный ELF-бинарник для Linux.

## Подготовка и зависимости

Для работы с исходным кодом и сборки потребуется Python 3.8+ и несколько пакетов. 

Установка зависимостей:

```bash
pip install pillow pyinstaller
```

(Pillow нужен для сглаживания и масштабирования изображений, а PyInstaller для сборки в бинарники).

---

## Сборка релизных бинарнико

По условиям, запуск должен производиться из скомпилированных файлов, а не через интерпретатор.

### Сборка в бинарник на Windows:
```cmd
pyinstaller --noconsole --onefile button_app.py
```
*Исполняемый файл появится по пути: `dist\button_app.exe`*

### Сборка в бинарник Linux-машине:
```bash
pyinstaller --noconsole --onefile display_app.py
```
*Исполняемый файл появится по пути: `dist/display_app`*

---

## Инструкция по запуску

1. **Подготовка сети**: убедитесь, что оба компьютера подключены к одной локальной сети.

2. **Подготовка контента**: сделать так, что папка `images` с любыми фотографиями находилась в одной папке с исполняемым файлом `display_app`.

3. **Запуск Приёмника**: Откройте `display_app` на Linux.

4. **Запуск Отправителя**: Откройте `button_app.exe` на Windows.

5. Нажмите кнопку на Windows — изображение на Linux мгновенно переключится.
